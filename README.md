# Skills Pack for Cue / Manus Agents

A pack of reusable agent skills: a 13-skill YouTube set for running faceless channels end to end, plus a design set (design taste, polish, anti-slop).

## Skills

- **yt-plan**: channel and video planning
- **yt-script**: script writing with hook scoring (includes hookscore.py)
- **yt-package**: titles and thumbnail text as one pairing (includes title.py lint)
- **yt-seo**: descriptions, tags, and metadata
- **yt-chapters**: timestamp chapters (includes chapters.py)
- **yt-retention**: retention structure and pacing checks (includes retention.py)
- **yt-shorts**: standalone Shorts production
- **yt-clips-skill**: clipping long videos into Shorts
- **yt-viral**: viral angle analysis (includes swipe.py)
- **yt-comment**: comment engagement
- **yt-edit**: editing support (includes deadair.py)
- **yt-audit**: channel and video audits
- **youtube-thumbnail**: thumbnail design

Each skill lives in its own folder with a SKILL.md.

## Design skills

- **design-taste-frontend**: concept-first frontend and visual design, idea from the subject, anti generic-AI-slop
- **impeccable**: design polish and QA pass
- **antislop**: detect and remove AI-slop patterns from copy and design
